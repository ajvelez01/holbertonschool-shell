- `0-alias`: creates the alias ls with the value rm -f *.
- `1-hello_you`: prints "hello user", where user is the current Linux user.
- `2-path`: adds /action to the end of the PATH variable. Run it with source.
- `3-paths`: counts the number of non-empty directories in the PATH variable. Run it with source or as a script.
- `4-global_variables`: lists the environment variables.
- `5-local_variables`: lists all local variables, environment variables and functions.
- `6-create_local_variable`: creates the local variable BEST with the value School. Run it with source.
- `7-create_global_variable`: creates the global variable BEST with the value School. Run it with source.
- `8-true_knowledge`: prints the result of adding 128 to the value of the environment variable TRUEKNOWLEDGE.
- `9-divide_and_rule`: prints the result of POWER divided by DIVIDE, the environment variables, followed by a new line.
- `10-love_exponent_breath`: displays the result of BREATH to the power of LOVE, using the environment variables.
- `11-binary_to_decimal`: converts the number stored in the environment variable BINARY from base 2 to base 10.
- `12-combinations`: prints all two-letter lowercase combinations, one per line, except oo.
- `13-print_float`: prints the number stored in NUM with two decimal places, followed by a new line.
