# Shell, permissions

- `0-iam_betty`: switches the current user to the user betty.
- `1-who_am_i`: prints the effective username of the current user.
- `2-groups`: prints all the groups the current user is part of.
- `3-new_owner`: changes the owner of the file hello in /tmp to the user betty.
- `4-empty`: creates an empty file called hello in the current directory.
- `5-execute`: adds execute permission to the owner of the file hello in the current directory.
- `6-multiple_permissions`: adds execute permission to the owner and group, and read permission to others, for the file hello in the current directory.
- `7-everybody`: adds execute permission to the owner, the group and the other users for the file hello in the current directory.
- `8-James_Bond`: sets the permissions of the file hello to none for the owner and group, and all for other users.
- `9-John_Doe`: sets the mode of the file hello to rwxr-x-wx.
- `10-mirror_permissions`: sets the mode of the file hello to the same mode as the file olleh.
- `11-directories_permissions`: adds execute permission for the owner, the group and other users to all subdirectories of the current directory.
- `12-directory_permissions`: creates a directory called my_dir with permissions 751 in the current directory.
