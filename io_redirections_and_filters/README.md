# I/O Redirections and Filters

- `0-hello_world`: prints "Hello, World" followed by a new line to the standard output.
- `1-confused_smiley`: displays a confused smiley "(Ôo)'.
- `2-hellofile`: displays the content of the /etc/passwd file.
- `3-twofiles`: displays the content of /etc/passwd followed by /etc/hosts.
- `3-twofiles`: displays the content of /etc/passwd followed by /etc/hosts.
- `4-lastlines`: displays the last 10 lines of /etc/passwd.
- `5-firstlines`: displays the first 10 lines of /etc/passwd.
- `6-third_line`: displays the third line of the file iacta in the working directory.
- `7-file`: creates a file with a strange name containing the text "Best School" followed by a new line.
- `7-file`: creates a file with a strange name containing the text "Best School" followed by a new line.
- `8-cwd_state`: writes the output of ls -la into ls_cwd_content, overwriting it if it exists.
- `9-duplicate_last_line`: duplicates the last line of the file iacta in the working directory.
- `10-no_more_js`: deletes all regular files with a .js extension in the current directory and its subdirectories.
- `11-directories`: counts the directories and subdirectories in the current directory, including hidden ones.
- `12-newest_files`: displays the 10 newest files in the current directory, one per line, from newest to oldest.
- `13-unique`: reads a list of words from standard input and prints, sorted, only the words that appear exactly once.
- `14-findthatword`: displays the lines containing the pattern root from /etc/passwd.
- `15-countthatword`: displays the number of lines containing the pattern bin in /etc/passwd.
- `16-whatsnext`: displays lines containing the pattern root from /etc/passwd and the 3 lines after each match.
- `17-hidethisword`: displays the lines of /etc/passwd that do not contain the pattern bin.
- `18-letteronly`: displays the lines of /etc/ssh/sshd_config that start with a letter.
- `19-AZ`: replaces all characters A with Z and c with e in the input.
